# Hi there, I'm Sebastian! 👋

I'm a **Python Backend Developer** with a passion for **Software Engineering** and a deep love for the stars. I enjoy bridging the gap between high-level code and physical hardware, creating solutions that make life (and stargazing) easier.

---

### 🌌 Astronomy & Astrophotography
When I'm not coding, I'm looking up. I build my own tools to capture the universe:
* **Astro-Controller:** Custom ESP32-based controller (MicroPython) for focusers, dew heaters, and automatic flatpanels.
* **Astrophotography:** Capturing deep sky objects using a mix of DIY hardware and precision software. Check out my work on [Instagram](https://www.instagram.com/astrozapal/).

### 🏠 Smart Home Enthusiast
My home runs on **Home Assistant** and **Node-Red**, hosted on **Proxmox**. I believe everything should be automated:
* **Ever UPS Integration:** Creator of the Home Assistant addon for Ever UPS devices (available via **HACS**).
* **Garden Automation:** Smart irrigation system and a mailbox sensor that notifies me when mail arrives.
